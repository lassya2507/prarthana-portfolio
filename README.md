## 🌷 What I wanted this portfolio to feel like

I did not want a generic developer portfolio.

I wanted something that still felt like **me**: technically serious, recruiter-friendly, a little dreamy, and very intentionally cute-tech. 🎀

The design combines soft pink and lavender tones, elegant serif typography, subtle motion, and interactive elements while keeping the actual engineering work easy to scan.

## 🫧 Highlights

- 🌙 Light and dark mode
- 🌊 Soft animated ripple / fluid background
- 🎀 Pastel, feminine, cute-tech visual system
- 🤖 **Mini Prarthana**, a resume-aware AI assistant
- 💻 Experience and project sections focused on measurable engineering impact
- 📱 Responsive design for desktop and mobile
- ✨ Subtle interactive motion without sacrificing readability
- ♿ Reduced-motion friendly behavior

## 🤖 Mini Prarthana

One of my favorite parts of the site is **Mini Prarthana**, a small AI assistant designed to answer questions about my experience, projects, and resume.

Try asking things like:

- What did you build at GoSentrix?
- What kind of AI systems do you work on?
- What projects are you most proud of?
- What roles are you targeting for 2027?

## 🚀 Run locally

```bash
git clone https://github.com/lassya2507/prarthana-portfolio.git
cd prarthana-portfolio
npm install
npm run dev
```

The local development URL will be printed in your terminal.

## 🔐 Environment variables

This repository includes an `.env.example` file for the expected environment configuration.

Create your own local `.env` file if needed:

```bash
cp .env.example .env
```

Then add your own values locally.

**Never commit real API keys, tokens, or secrets.**
